# 음주진단 자가진단 체크리스트 시스템

한국도로교통공단 교통안전교육 현장에서 사용하는 **운전성향 자가진단 체크리스트** 웹 애플리케이션입니다.

강의자가 QR코드를 보여주면 학습자가 스마트폰으로 접속해 설문에 응답하고, 강의자는 실시간으로 결과를 확인·분석·공유할 수 있습니다.

---

## 실행 방법 (2단계)

### 1. 설치

프로젝트 폴더에서 아래 명령을 **한 번만** 실행합니다.

```bash
npm install
```

> Node.js 22.5 이상이 필요합니다 (내장 SQLite 사용).
> [https://nodejs.org](https://nodejs.org) 에서 LTS 버전을 설치하세요.

### 2. 실행

```bash
npm start
```

실행하면 터미널에 접속 주소가 표시됩니다.

```
학습자 접속:  http://192.168.x.x:3000
관리자 페이지: http://192.168.x.x:3000/admin
공유 화면:    http://192.168.x.x:3000/share
```

## 무료 인터넷 게시(Render Free)

무료로 먼저 인터넷 접속 테스트를 해볼 때는 Render Free Web Service를 사용할 수 있습니다.

> 주의: Render 무료 서버는 일정 시간 접속이 없으면 잠들 수 있고, 서버가 재시작되면 내부 SQLite 데이터가 사라질 수 있습니다. 교육장 계정과 응답 데이터는 장기 보관용으로 보지 말고, 당일 테스트 또는 가벼운 시범 운영용으로 사용하세요.

### 1. GitHub에 코드 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 프로젝트 폴더 내용을 저장소에 업로드합니다.
3. `node_modules`, `client/dist`, `server/data/*.db` 파일은 올리지 않습니다. 이 항목들은 `.gitignore`에 제외되어 있습니다.

### 2. Render에서 무료 Web Service 만들기

1. [https://render.com](https://render.com)에 로그인합니다.
2. `New` → `Web Service`를 선택합니다.
3. GitHub 저장소를 연결합니다.
4. Instance Type은 `Free`를 선택합니다.
5. 저장소에 포함된 `render.yaml` 설정을 사용해 배포합니다.

Render 설정을 직접 입력해야 할 경우 아래 값을 사용합니다.

| 항목 | 값 |
|------|----|
| Runtime | Node |
| Build Command | `npm install && npm run build` |
| Start Command | `npm run start:server` |
| Node Version | `22.16.0` |

### 3. 배포 후 확인

배포가 완료되면 Render에서 제공하는 `https://...onrender.com` 주소로 접속합니다.

| 구분 | 주소 |
|------|------|
| 학습자 | `https://배포주소` |
| 관리자 | `https://배포주소/admin` |
| 공유 화면 | `https://배포주소/share` |

초기 최고관리자 로그인 정보:

- 교육장명: `관리자`
- 비밀번호: `1234` 또는 로컬에서 변경한 기본 비밀번호

## 사용 흐름

```
강의자 PC에서 npm start 실행
        ↓
관리자 페이지(/admin)에서 QR코드 확인
        ↓
학습자 스마트폰으로 QR 스캔 또는 주소 입력
        ↓
기본정보 입력 → 음주운전 성향 → 음주운전 성향 → 음주운전 성향
        ↓
개인 결과 확인
        ↓
강의자: 결과 공개 → /share 화면으로 전체 통계 발표
        ↓
Excel / PDF 다운로드
```

## 접속 주소

| 구분 | 주소 |
|------|------|
| 학습자 | `http://[서버IP]:3000` |
| 관리자 | `http://[서버IP]:3000/admin` |
| 공유 화면 | `http://[서버IP]:3000/share` |

- **인터넷 없이** 같은 Wi-Fi, 모바일 핫스팟, 로컬 네트워크에서 사용 가능합니다.
- 서버 IP는 실행 시 자동으로 탐색됩니다.

## 주요 기능

### 학습자 (1단계)
- QR코드 / URL 접속
- 기본정보 입력 (성별, 연령대, 운전경력, 차종)
- 음주운전 성향 / 음주운전 성향 / 음주운전 성향 체크리스트 (7점 리커트 척도)
- 개인 결과 확인
- 동일 기기·동일 회차 중복 응답 방지

### 관리자 (1단계)
- 로그인 및 비밀번호 변경
- 실시간 응답 현황 (접속자, 완료, 진행 중)
- 통계 차트 (성별, 연령대, 운전성향 등)
- 응답자 목록
- Excel 다운로드 (`driving_checklist_results.xlsx`)

### 고도화 (2단계)
- 교육 회차 관리 (새 회차 생성)
- 응답 시작 / 종료
- 결과 공개 / 숨김
- 공유 결과 페이지 (3초마다 자동 갱신)
- 발표 모드
- PDF 결과보고서
- 데이터 자동 백업

## 프로젝트 구조

```
├── package.json          ← 루트 실행 (npm install / npm start)
├── client/               ← React + Vite 프론트엔드
│   └── src/
│       ├── pages/        ← 학습자·관리자·공유 화면
│       └── components/
└── server/               ← Node.js + Express 백엔드
    ├── data/
    │   ├── questions.js      ← ★ 체크리스트 문항 (PDF 기준)
    │   ├── resultRules.js    ← ★ 점수·결과 구간 (PDF 기준)
    │   ├── checklist.db      ← SQLite DB (자동 생성)
    │   └── backups/          ← 백업 파일
    ├── routes/
    └── index.js
```

### 문항·결과 수정 방법

PDF 내용을 변경할 때는 아래 두 파일만 수정하면 됩니다.

- `server/data/questions.js` — 문항 텍스트, 섹션 구성
- `server/data/resultRules.js` — 점수 구간, 결과 설명

수정 후 `npm start`로 서버를 다시 실행하면 반영됩니다.

## 문제 해결

### npm install 오류
- Node.js 22.5 이상 설치 확인: `node -v`

### 학습자 기기에서 접속 안 됨
- 강의자 PC와 학습자 기기가 **같은 Wi-Fi/핫스팟**에 연결되어 있는지 확인
- Windows 방화벽에서 Node.js(포트 3000) 허용
- 터미널에 표시된 IP 주소를 정확히 입력

### 데이터 백업
- 관리자 → 설정 → **지금 백업하기**
- 백업 파일 위치: `server/data/backups/`
